# Local Documentation

Generated documentation is produced with JSDoc.

## Generate documentation

```bash
npm run docs
```

The generated HTML documentation is saved to `docs/`. Open `docs/index.html` locally to view it.

## Video requirement

If the documentation is not deployed to a public server, record a short video that shows:

1. running `npm run docs`;
2. opening `docs/index.html`;
3. navigating generated component documentation;
4. running `npm run storybook` and opening two documented components.

Recommended file name for the video: `documentation-demo.mp4`. Add the video to the submitted GitHub repository or attach it in the learning system if large media files are not accepted in Git.
