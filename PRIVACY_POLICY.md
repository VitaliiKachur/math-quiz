# Privacy Policy and User Guide

## Project

Math Quiz is a local educational React application for practicing arithmetic operations.

## Data processing

The application does not send personal data to a remote server. Data is stored in the browser on the user's device through `localStorage`.

Stored data can include:

- selected quiz settings;
- latest game history;
- cookie consent configuration;
- player name entered before a quiz session.

## GDPR consent

The cookie popup separates consent into:

- necessary storage, required for the application interface;
- preferences, used for game settings;
- analytics, reserved for anonymous learning statistics.

The user may accept all categories, accept only necessary storage, or save a custom selection.

## User rights

The user can clear stored browser data at any time through browser settings or by clearing game history in the application. Because the project has no public backend, data export, correction and deletion are performed locally on the user's device.

## Usage restrictions

This project is provided for educational use in the Component-Oriented Programming course. It should not be used as a medical, financial, legal or high-stakes testing system.
